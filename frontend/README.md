Panopticon --- Frontend

Panopticon is an AI-powered fraud intelligence platform designed for
transaction monitoring, graph-based fraud investigation, risk analysis,
and alert management.

This directory contains the Next.js frontend for the Panopticon
platform.

Tech Stack

Next.js --- React framework using the App Router

React

TypeScript

Tailwind CSS

Framer Motion --- UI animations

Lucide React --- interface icons

Recharts --- analytics and chart visualizations

React Force Graph 2D --- graph visualization

FastAPI backend --- consumed through the Panopticon API

Frontend Features

The frontend provides:

Landing page

Authentication / operator login

Console Dashboard

Transaction monitoring

Graph Explorer

Fraud Alerts

Case Management

Analytics and charts

Design Settings / Sandbox

The application communicates with the Panopticon FastAPI backend through
the configured API URL.

Backend API

Production API:

https://panopticon-graph-ai.onrender.com

API documentation:

https://panopticon-graph-ai.onrender.com/docs

The frontend uses the environment variable:

NEXT_PUBLIC_API_URL

If it is not provided, the application falls back to:

https://panopticon-graph-ai.onrender.com

Getting Started

1. Install dependencies

npm install

2. Configure the API

Create .env.local in the frontend root:

NEXT_PUBLIC_API_URL=https://panopticon-graph-ai.onrender.com

For local backend development:

NEXT_PUBLIC_API_URL=http://127.0.0.1:8000

Restart the Next.js server after changing environment variables.

3. Start development server

npm run dev

Open:

http://localhost:3000

Authentication

Login uses:

POST /api/v1/auth/login

Request format:

{
  "email": "admin@panopticon.com",
  "password": "Admin@123"
}

A successful login returns a bearer access token.

For the development/demo environment:

Email: admin@panopticon.com
Password: Admin@123

Do not use development credentials in production.

Main API Areas

The frontend communicates with backend endpoints covering:

Authentication

POST /api/v1/auth/register
POST /api/v1/auth/login
GET  /api/v1/auth/me

Transactions

POST /api/v1/transactions
GET  /api/v1/transactions
GET  /api/v1/transactions/suspicious
GET  /api/v1/transactions/{transaction_id}

Dashboard

GET /api/v1/dashboard/summary

Graph

GET /api/v1/graph
GET /api/v1/graph/{node_id}

Alerts

GET /api/v1/alerts

Production Build

Create a production build:

npm run build

npm start

Deployment

The frontend can be deployed to a Next.js-compatible hosting platform
such as Vercel or Render.

Set the production environment variable:

NEXT_PUBLIC_API_URL=https://panopticon-graph-ai.onrender.com

The backend must permit requests from the deployed frontend origin
through its CORS configuration.

Troubleshooting

API requests fail

Check:

NEXT_PUBLIC_API_URL

Backend availability

Backend /docs endpoint

Browser Network tab

Request URL and HTTP method

Request payload

Response status and body

Browser console errors

Authentication returns 422

Inspect the response body for the backend validation message. A
422 Unprocessable Entity means the submitted request does not match
the backend validation schema.

React runtime error while displaying an API error

Backend errors can contain structured objects or arrays. Convert
structured error details to a string before rendering them directly in
React.
